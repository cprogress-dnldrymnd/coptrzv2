# This block does NOT belong in this git repository — it belongs in
# app/public/.htaccess (the WordPress site root), OUTSIDE wp-content/themes/coptrz
# entirely. That file has no version control of its own, so this is the only
# place this content is preserved. To deploy: paste this block into
# app/public/.htaccess, between the existing "# BEGIN WordPress" / "# END WordPress"
# markers and anything after them — order relative to the WordPress block doesn't
# matter, mod_rewrite and mod_headers are independent.
#
# This is a mirror of dd_send_security_headers() in
# wp-content/themes/coptrz/includes/hooks.php (branch: security-headers, commit
# 480fb915's state — the CSP-only revert: enforcing origin-allowlist script-src
# rolled back to frame-ancestors-only, everything else from the hardening pass
# kept). Needed because on a LiteSpeed full-page-cache HIT the PHP-emitted
# headers are bypassed entirely — this is the only path that guarantees the
# headers on a cached response. KEEP THIS IN SYNC with hooks.php manually if
# that policy ever changes — there is no shared source between the two.
#
# CSP is frame-ancestors-only, same everywhere (no admin/login split needed):
# an enforcing origin-allowlist script-src was trialled 2026-07 and rolled
# back — chasing every third-party integration's exact origins (Booqable's
# separate booqableshop.com apex, RevenueHunt, reCAPTCHA, Google Ads/doubleclick,
# Hotjar's two TLDs, OpenAI Ads' two subdomains, a missing media-src for product
# videos) turned into ongoing whack-a-mole. Revisit only with a nonce-based
# approach if this comes up again.

# BEGIN Coptrz Security Headers
<IfModule mod_headers.c>
Header always unset X-Powered-By
Header always set X-Content-Type-Options "nosniff"
Header always set X-Frame-Options "SAMEORIGIN"
Header always set Referrer-Policy "strict-origin-when-cross-origin"
Header always set Permissions-Policy "camera=(), microphone=(), geolocation=(), usb=(), serial=(), interest-cohort=(), payment=(self)"
Header always set Cross-Origin-Opener-Policy "same-origin-allow-popups"
Header always set Content-Security-Policy "frame-ancestors 'self'"

# HTTPS only, mirrors the is_ssl() check in dd_send_security_headers().
Header always set Strict-Transport-Security "max-age=31536000" env=HTTPS
</IfModule>
# END Coptrz Security Headers
